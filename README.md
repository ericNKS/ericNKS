### 🔬 Research

**Performance Analysis of Supervised Machine Learning Algorithms for Credit Transaction Fraud Detection**
*Undergraduate thesis (TCC) — Centro Universitário Jorge Amado (UNIJORGE)*

Applied, quantitative/experimental research comparing supervised ML algorithms — **Logistic Regression, XGBoost and Random Forest** — for detecting fraudulent credit transactions, motivated by the R$10.1B+ in fraud losses reported in Brazil in 2024. The work involves a systematic literature review (ACM Digital Library, IEEE Xplore, SciELO, Google Scholar), dataset preprocessing for class imbalance, and model evaluation using **Confusion Matrix, Precision, Recall, F1-Score and AUC** to identify the most effective approach for minimizing financial loss and false positives.

`Python` · `scikit-learn` · `XGBoost` · `Pandas` · `NumPy` · `Machine Learning` · `Fraud Detection`
